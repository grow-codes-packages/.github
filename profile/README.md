# Grow Codes Packages

[![Grow Codes](https://img.shields.io/badge/Grow%20Codes-grow.codes-2ea44f)](https://grow.codes)

Grow Codes Packages is building Apache-2.0 SDKs for secrets management, logging, and distributed tracing. Each service has one repository for its TypeScript, Rust, Go, Python, and Java packages. Those packages share the same behavior and are tested against the corresponding service or a documented cloud test environment.
