# Contributing

Open an issue in the affected SDK repository for bugs and feature proposals. Include the SDK language and version, service version, expected and observed behavior, and relevant context with sensitive data removed. Follow our security policy for vulnerabilities and our code of conduct for community participation. [Security policy][security] · [Code of conduct][conduct]

For a pull request, follow the repository's setup and validation instructions. A change to public behavior should account for all five SDKs. Update the documentation and conformance cases when behavior changes, and include the checks you ran.

Keep client implementations independent of upstream service code. If you use upstream API definitions, follow the affected repository's license and attribution rules.

[security]: https://github.com/grow-codes-packages/.github/blob/main/SECURITY.md
[conduct]: https://github.com/grow-codes-packages/.github/blob/main/CODE_OF_CONDUCT.md
