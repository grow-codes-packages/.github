# Grow Codes Packages organization repository

This repository holds the public organization profile and the default community health files for SDK repositories.

- Update `profile/README.md` when a service repository opens or a package is released. Check the public repository and its release or registry listing before marking an SDK available.
- Keep `SECURITY.md`, `CONTRIBUTING.md`, and `CODE_OF_CONDUCT.md` in the root and the issue and pull request templates under `.github/`.
- Keep contact information consistent across the policy and templates. Report security concerns through the channel in `SECURITY.md`.
- Validate Markdown tables, links, and issue template YAML before opening a pull request against `main`.
