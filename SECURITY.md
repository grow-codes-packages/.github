# Security Policy

Report suspected vulnerabilities privately to [opensource@grow.codes](mailto:opensource@grow.codes). If the affected repository has enabled private vulnerability reporting, you can submit through **Security → Advisories → Report a vulnerability**. [GitHub private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the affected repository, package and version, the conditions where the issue occurs, the potential impact, and a way to contact you. Redact credentials and customer data. Keep vulnerability details in the private report while we coordinate disclosure.
